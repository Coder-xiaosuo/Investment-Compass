# A 股支撑阻力（阶段二参考）

> 本文件在 detected_patterns 包含 `integer_level` 或 `chip_dense` 时加载。

【A 股整数关口】
- 10/20/50/100 元等整数价位是 A 股最重要的心理价位
- 整数关口附近的支撑/阻力可靠性高于 Brooks 趋势线
- 整数关口 + 前高/前低重叠 → 强支撑/阻力

【筹码密集区】
- A 股筹码密集区（前期横盘区间）是强支撑/阻力
- 放量突破密集区后回踩 → 好的入场机会
- 缩量触及密集区 → 大概率被阻挡

【前期高低点】
- 前期高点：突破后转为支撑（支撑阻力互换）
- 前期低点：跌破后转为阻力
- A 股的前高/前低有效性高于外汇（散户记忆效应）

【规则】
- 支撑/阻力位的可靠性排序：整数关口+前高/前低叠加 > 整数关口 > 前高/前低 > 趋势线
- 支撑/阻力位附近禁止追市价单
