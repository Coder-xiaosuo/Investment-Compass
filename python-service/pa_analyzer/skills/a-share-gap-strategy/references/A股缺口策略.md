# A 股缺口策略（阶段二参考）

> 本文件在 detected_patterns 包含 `gap_breakout` 或 `gap_exhaustion` 时加载。

【A 股缺口分类】
- 突破缺口：突破关键价位/区间时出现的跳空，放量且不回补
- 中继缺口：趋势中途的跳空，通常 3-10 日内不回补
- 衰竭缺口：趋势末端出现的跳空，随后迅速回补

【诊断规则】
- 突破缺口 + 放量（量比>2）→ 可信度高，可作为趋势确认信号
- 缺口 3 日内回补 → 大概率假突破，gate_result=wait
- 衰竭缺口出现 → 趋势末端，禁止追方向，仅 wait

【A 股缺口特征】
- A 股跳空缺口远比外汇/期货常见（政策面驱动）
- 缺口支撑/阻力有效性：突破缺口 > 衰竭缺口（前者未回补则长期有效）
- 整数关口附近的缺口可靠性更高
- 下跌趋势中的向下跳空缺口 → 更大概率持续下行，不轻易抄底
