# 数据读取规范

> 文档系列：数据中台（`docs/data-platform/`）
> 本文档：03-数据读取规范
> 关联文档：[01-总体架构](./01-总体架构.md) / [02-数据写入链路](./02-数据写入链路.md)

## 1. 定位与范围

本规范定义 Java 后端与 Python 侧**读取** MySQL 数据时的统一约定：查询语义、字段口径、排序规则，以及两侧实现差异的注意事项，避免"同一字段两侧口径不一致"。

**写入方为 Python（唯一），读取方为 Python + Java，本规范仅覆盖读取侧。**

## 2. 读取边界

| 表 | Python 读 | Java 读 | 说明 |
|---|---|---|---|
| `market_data` | K线历史、实时行情、最新日期 | K线、行情、详情、指标、大盘、覆盖率 | 核心读取表 |
| `stock_metadata` | 股票名称、搜索 | 搜索、详情、后缀补全、覆盖率 | — |
| `sync_task` | — | backfill 进度 | Java 只读 |
| `data_quality_issue` | — | 质量 issue 列表 + 状态流转 | Java 仅更新 status |
| `watchlist` | — | 自选股 | — |
| `conversation` / `message` | 对话 | — | Python 独占 |

## 3. 字段语义对齐（两侧一致约定）

| 字段 | 语义 | 约束 |
|---|---|---|
| `symbol` | 股票代码，**含交易所后缀**（如 `000001.SZ`） | Java 侧对无后缀入参自动补全（见 §5.2）；两侧查询必须精确匹配一致格式 |
| `trade_date` | A 股交易日（date） | 由写入时 `ts_open` 换算，UTC 时区 |
| `ts_open` | K 线开盘 Unix **毫秒**时间戳（UTC） | 转秒需 `/1000` |
| `timeframe` | 周期：1m/5m/15m/30m/1h/4h/1d | 周线 `1w`、月线 `1M` 为 Java 侧聚合产物，**不落库** |
| `open/high/low/close` | OHLC 价格（double） | 已保证 low ≤ close ≤ high |
| `volume` | 成交量（股，bigint） | 非负 |
| `amount` | 成交额（元，double） | 缺失时 Python 写 0.0 |
| `pct_chg` | 涨跌幅（%），正涨负跌 | 由数据源提供；`closed` 未收盘的最新 K 线为盘中值 |
| `closed` | 1=已收盘，0=正在形成 | 交易时段内最新一根为 0 |

## 4. Python 侧读取规范

入口：[market_data_service.py](../../python-service/services/market_data_service.py)。

### 4.1 K 线历史 `get_kline_history`

- 参数：`symbol` + `timeframe`（默认 1d）+ `start_date` / `end_date` / `limit`（默认 120）
- SQL：`trade_date DESC LIMIT :limit`，结果 `reversed` 后**按日期升序返回**
- **日期范围与 limit 并存**：提供 start/end 时仍带 `LIMIT`（与 Java"日期范围优先、忽略 limit"语义不同，见 §7）
- `timeframe` 匹配不区分大小写（`LOWER(timeframe) = LOWER(:tf)`）
- 返回 bar 缺省值兜底：数值缺省 0，`pct_chg`/`closed` 兜底 None / 1

### 4.2 实时行情 `get_realtime_quote`

- 取每只股票最新一条 `market_data`（`ORDER BY trade_date DESC LIMIT 1`）
- `pre_close`：**自连接查上一交易日 close**（`SELECT MAX(trade_date) ... < 当前`），非反推

### 4.3 其他

- `get_latest_market_date`：`SELECT MAX(trade_date)`，供增量同步判断
- 财务/行业/估值：`financial_data_service` / `industry_service` / `valuation_service`（指标经 `_INDICATOR_MAP` 映射，如 ROE/毛利率/负债率等）

## 5. Java 侧读取规范

### 5.1 K 线历史（[StockService.getKlineHistory](../../java-backend/src/main/java/com/xiaosuo/investmentcompass/service/StockService.java#L139-L218)）

- 入参校验：symbol / timeframe 非空
- **日期范围优先于 limit**：`startDate + endDate` 同时提供时忽略 limit；否则 `ORDER BY trade_date DESC + LIMIT`，再 `Collections.reverse` 转**升序**
- 周期映射：`1w` / `1M` 走聚合（queryTimeframe = `1d`，limit × 5 拉取后再聚合裁剪），其余周期直查
- 聚合规则（周/月线）：`open=组首`，`high/low=组内最大/最小`，`close=组尾`，`volume/amount=求和`，`pct_chg=(close/open−1)×100`，`closed=1`（恒）

### 5.2 Symbol 后缀补全（[resolveSymbol](../../java-backend/src/main/java/com/xiaosuo/investmentcompass/service/StockService.java#L114-L123)）

- 入参含 `.` 直接使用；否则 `stock_metadata.symbol LIKE 'code%' LIMIT 1` 补全
- 依赖 `stock_metadata` 中存在带后缀记录；补全失败时退回原值（查询可能空结果）

### 5.3 实时行情 `getLatestQuote`

- `MarketDataMapper.selectLatestQuote`：每只股票最新一条
- `pre_close`：**由 pct_chg 反推** `close / (1 + pct/100)`（与 Python 自连接口径不同，见 §7）

### 5.4 指标计算 `getIndicators`

- 基于 1d K 线在 Java 侧计算：`ma`（默认 20）/ `ema`（默认 12）/ `macd`
- 空值为 NaN，输出转 `null`

### 5.5 监控与看板（MonitorService / MarketBoardService）

- `/monitor/overview`：stock_metadata 启用数、market_data 覆盖数
- `/monitor/backfill-progress`：读 `sync_task`
- `/monitor/coverage`：`market_data` 各 symbol 最新交易日
- `/monitor/quality-issues`：读 `data_quality_issue`，可更新 status
- `/market/indices` `/market/ranking`：market_data 排序聚合

## 6. 实时行情读取

- **Redis Hash**：`quote:{symbol}`（6 位 code），字段含 name/price/change_pct/open/high/low/volume/amount/timestamp
- **Pub/Sub**：频道 `quotes`，整批 JSON 数组广播
- **消费端**：`QuoteRedisSubscriber` 订阅 → 按需分发给 WebSocket session（`QuoteWebSocketSessionManager`）
- 实时口径仅覆盖**盘口快照**，不落库；持久化查询一律走 MySQL

## 7. 两侧差异与注意项（待对齐）

| # | 差异点 | Python | Java | 影响 |
|---|---|---|---|---|
| 1 | `pre_close` 口径 | 查上一交易日 close | `close/(1+pct/100)` 反推 | 数据源 pct 与行情不一致时结果有偏差 |
| 2 | 日期范围与 limit | 并存（仍 LIMIT） | 日期范围优先、忽略 limit | 同参返回条数可能不同 |
| 3 | 周/月线 | 无聚合实现 | Java 侧聚合（1w/1M） | 依赖 1d 数据完整性；聚合 `pct_chg` 基准为 open，非前收 |
| 4 | `symbol` 格式 | 依赖调用方传入 | 自动补后缀 | Python 写入原始入参，格式不一时同股票可能存多行 |
| 5 | `volumeRatio`/`turnoverRate` | 无 | 占位：turnoverRate 简易估算、volumeRatio=1.0 | 前端如展示量比会失真 |
| 6 | `timeframe` 大小写 | LOWER 匹配 | 精确匹配 | 写入须统一小写（当前写入固定 `1d`） |

**建议**：
1. `pre_close` 两侧统一为"查上一交易日 close"（Python 口径），Java 侧去掉反推。
2. `market_data.symbol` 写入统一为**带后缀格式**，Python 侧 `bars_to_rows` 前归一化。
3. 补齐 Python 侧周/月线聚合，或明确"周月线仅由 Java 提供"。
4. 量比/换手率：明确口径来源后再决定是否移除占位值。

## 8. 查询约定速查

| 场景 | 约定 |
|---|---|
| K 线返回顺序 | 两侧均为**日期升序** |
| 默认返回数量 | 120 根（1d） |
| 日期格式 | `YYYY-MM-DD` |
| 时间戳单位 | `ts_open` 毫秒（UTC）；展示侧转本地时区 |
| 未收盘标记 | `closed=0` 仅出现在交易时段最新一根 |
| 代码格式 | 优先带后缀；Java 可自动补全，Python 需调用方保证 |
