## 1. 设计原则

### 1.1 三栏式工作台核心原则

1. **对话即界面** - 中央对话流是核心交互区
2. **渐进式信息披露** - 点击左侧股票->右侧展示详情
3. **可执行卡片** - AI建议以动作卡片呈现

### 1.2 与已有设计系统的关系

复用 frontend/src/style.css 全部 CSS 变量

## 2. 布局架构

### 2.1 整体布局

三栏式: 左侧面板(280px) | 中央主操作区(flex:1) | 右侧面板(320-480px可拖拽)

### 2.2 间距规范

面板padding: 16px (--space-4)
卡片gap: 12px (--space-3)
对话消息gap: 16px (--space-4)

## 3. 核心组件

### 3.1 LeftPanel
- AssetOverview: 资产概览卡片
- HoldingList: 持仓列表
- StockSearch: 股票搜索框
- StockDataPanel: 股票数据摘要(条件渲染)

### 3.2 CenterPanel
- ConversationFlow: 对话流
- MessageBubble: 消息气泡(复用)
- DataCard: 数据卡片(新建)
- ActionCard: 动作卡片(新建)
- QuickActions: 快捷操作栏
- InputArea: 输入框

### 3.3 RightPanel
- DefaultMode: TodoList + ContextView
- SearchMode: KLineChart + StockSummary

### 3.4 BottomBar
底部状态栏 32px, 显示工作流/数据/AI状态

## 4. 状态管理

新增 Store:
- workbenchStore: 布局状态
- portfolioStore: 持仓与资产
- marketStore: 行情快照
- searchStore: 搜索状态

## 5. 路由规划

- /workbench: AgentWorkbench 主页面
- /classic/*: 旧页面回退

## 6. 开发优先级

阶段一: 骨架搭建(三栏布局+基础面板)
阶段二: 核心交互(对话流+K线图+ActionCard)
阶段三: 全功能(待办+审批+状态栏)
