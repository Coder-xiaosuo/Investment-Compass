## 1. 整体架构

### 1.1 布局入口

操盘模式由 `MainArea.tsx` 渲染，顶部三 Tab 切换三个看板：

| Tab 标识 | 中文名 | 组件 | 布局 |
|----------|--------|------|------|
| `technical` | 技术面分析 | `TechnicalDashboard` | 五卡网格 `grid-cols-[1.7fr_1fr]` |
| `fundamental` | 基本面分析 | `FundamentalDashboard` | 五卡网格 `grid-cols-[1.7fr_1fr]` |
| `market` | 市场概览 | `MarketDashboard` | 五卡网格 `grid-cols-[1.7fr_1fr]` |

三看板统一布局：**左列上(2fr) + 左列下(1fr) + 右列三卡均分(grid-rows-3)**。

### 1.2 通用配色

- 红涨绿跌（A 股标准）：`UP='#dc2626'`（红）、`DOWN='#16a34a'`（绿）
- AI 分析按钮：浅蓝圆形 + Sparkles 图标，点击触发右侧对话栏按预设模板提问

### 1.3 卡片类型与 AI 预设提问

每个卡片右上角的「AI 分析」按钮对应 `CardType`，点击后通过 `CARD_PROMPTS[type]` 发起预设提问，共 15 种：

| CardType | 说明 | 所属看板 |
|----------|------|----------|
| `technical` | K 线技术分析 | 技术面 |
| `fundflow` | 资金流向分析 | 技术面 |
| `shareholder` | 股东变动分析 | 技术面 |
| `chip` | 筹码分布分析 | 技术面 |
| `target` | 目标价分析 | 技术面 |
| `financial` | 财务综合分析 | 基本面 |
| `cashflow` | 现金流分析 | 基本面 |
| `valuation` | 估值分析 | 基本面 |
| `growth` | 成长能力分析 | 基本面 |
| `solvency` | 偿债运营分析 | 基本面 |
| `indices` | 大盘指数分析 | 市场概览 |
| `breadth` | 涨跌宽度分析 | 市场概览 |
| `sectors` | 板块轮动分析 | 市场概览 |
| `northflow` | 北向资金分析 | 市场概览 |
| `mkvolume` | 成交量能分析 | 市场概览 |

## 2. 技术面分析看板

### 2.1 看板总览

| 卡片 | 组件文件 | API 端点 | 数据来源 |
|------|----------|----------|----------|
| K 线主图 | `KLineCard.tsx` | `GET /api/stock/kline` + `GET /api/stock/quote` + `GET /api/stock/detail/{symbol}` | Java 后端 (MySQL market_data 表) |
| 大单资金流向 | `FundFlowCard.tsx` | `GET /api/demo/fundflow` | Python 服务 (AkShare 实时) |
| 散户数量(股东户数) | `RetailCountCard.tsx` | `GET /api/demo/shareholders` | Python 服务 (AkShare 实时) |
| 收盘获利/筹码分布 | `ChipCostCard.tsx` | `GET /api/stock/kline` (60 日) | Java 后端 + 前端本地计算 |
| 预测目标价 | `TargetPriceCard.tsx` | 不调 API（从 `DecisionCardData.result` 解析）+ `GET /api/stock/kline` (趋势线) | 主控台 AI 决策结果 |

### 2.2 K 线主图 (KLineCard)

**功能**：三栏同步图表（主图 60% / 成交量 20% / 副图 20%），基于 `lightweight-charts` 库。

**周期切换**：`1m`(分时) / `1d`(日 K) / `1w`(周 K, 日线聚合) / `1M`(月 K, 日线聚合)

**副图指标**：`MACD` / `KDJ` / `BOLL` / `BIAS` 四选一（前端本地计算）

**MA 均线**：MA5 / MA10 / MA30（蓝色系 `['#3b82f6', '#60a5fa', '#a5b4fc']`）

**左栏价格面板显示字段**：

| 字段 | 来源 | 说明 |
|------|------|------|
| 当前价 | `detail.latestClose` ?? `quote.close` | 最新收盘价 |
| 涨跌幅 | `detail.changePercent` ?? `quote.changePct` | 百分比 |
| 涨跌额 | `detail.change` ?? `quote.close - quote.preClose` | 绝对值 |
| 股票名 | `detail.stockName` | 中文名称 |
| 今开 | `detail.latestOpen` | 当日开盘价 |
| 昨收 | `quote.preClose` | 前一交易日收盘价 |
| 最高 | `detail.latestHigh` | 当日最高 |
| 最低 | `detail.latestLow` | 当日最低 |
| 成交量 | `detail.latestVolume` | 转"万手" |
| 成交额 | `detail.latestAmount` | 转"亿/万" |
| 换手率 | `lastBar.turnover_rate` | >100 则除以 100 规范化 |

**KlineBar 数据结构**：

```typescript
interface KlineBar {
  symbol: string           // 股票代码
  trade_date: string       // 交易日期 yyyy-MM-dd
  timeframe: string        // 周期 1d/1w/1M
  ts_open: number          // 时间戳开盘(分时用)
  open: number             // 开盘价
  high: number             // 最高价
  low: number              // 最低价
  close: number            // 收盘价
  volume: number           // 成交量(手)
  amount: number           // 成交额(元)
  pct_chg: number          // 涨跌幅(%)
  closed: boolean          // 是否收盘
  volume_ratio: number     // 量比
  turnover_rate: number    // 换手率(%)
}
```

**技术指标计算**（前端 `@/lib/indicators.ts` 本地计算，不依赖后端）：

| 指标 | 函数 | 参数 | 输出 |
|------|------|------|------|
| MA | `calcMA(ohlc, period)` | period=5/10/30 | `ValuePoint[]` |
| MACD | `calcMACD(ohlc, 12, 26, 9)` | fast=12, slow=26, signal=9 | `MACDPoint[]` {dif, dea, hist} |
| KDJ | `calcKDJ(ohlc, 9)` | n=9, K/D 平滑=3 | `KDJPoint[]` {k, d, j} |
| BOLL | `calcBOLL(ohlc, 20, 2)` | period=20, mult=2 | `BOLLPoint[]` {mid, upper, lower} |
| BIAS | `calcBIAS(ohlc, [6,12,24])` | periods=6/12/24 | `ValuePoint[][]` |

### 2.3 大单资金流向 (FundFlowCard)

**API**：`GET /api/demo/fundflow?symbol={symbol}&days=10`

**两种展示模式**：

#### daily 模式（东财逐日序列，优先）

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 左侧汇总 | `summary.3d` / `5d` / `10d` | 3/5/10 日主力净流入合计 |
| 右侧柱状图 | `daily[].main_net` | 每日主力净流入（红入绿出双向柱） |
| Tooltip | `date` / `main_net` / `main_net_pct` | 日期、主力净额、净占比 |

```typescript
interface FundFlowData {
  symbol: string
  source: string                    // 数据源（同花顺/东财）
  mode: 'daily' | 'snapshot'
  daily?: FundFlowDailyRow[]
  summary?: { '3d'?: number; '5d'?: number; '10d'?: number }
  snapshot?: FundFlowSnapshot       // 降级快照
}

interface FundFlowDailyRow {
  date: string
  main_net: number                  // 主力净流入(元)
  super_net: number                 // 超大单净流入
  large_net: number                 // 大单净流入
  medium_net: number                // 中单净流入
  small_net: number                 // 小单净流入
  main_net_pct: number              // 主力净占比(%)
}
```

#### snapshot 模式（同花顺当日快照，降级）

| 字段 | 说明 |
|------|------|
| `snapshot.name` | 股票名 |
| `snapshot.price` | 当前价 |
| `snapshot.change_pct` | 涨跌幅 |
| `snapshot.turnover` | 换手率 |
| `snapshot.inflow` | 流入额 |
| `snapshot.outflow` | 流出额 |
| `snapshot.net` | 净额 |
| `snapshot.amount` | 成交额 |

### 2.4 散户数量/股东户数 (RetailCountCard)

**API**：`GET /api/demo/shareholders?symbol={symbol}`

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 最新一期 | `rows[0].count` | 最新股东户数 |
| 环比变化 | `rows[0].change_pct` | 增户绿/减户红 |
| 周期柱状图 | `rows[].count` | 归一化高度 |
| Tooltip | `date` / `count` / `change` / `change_pct` | 日期、户数、变化数、变化百分比 |

```typescript
interface ShareholdersData {
  symbol: string

}

interface ShareholderRow {
  date: string          // 报告期

}
```

### 2.5 收盘获利/筹码分布 (ChipCostCard)

**API**：`GET /api/stock/kline?symbol={symbol}&timeframe=1d&limit=60`（取最近 60 日 K 线）

**计算方式**：前端 `calcCostDistribution(bars, lastClose)` 本地计算筹码分布，不依赖后端。

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 左半上方 | `profitRatio` | 获利盘占比(%)(红色进度条) |
| 左半上方 | `trappedRatio` | 套牢盘占比(%)(绿色进度条) |
| 左半中部 | 现价 | 最新收盘价 |
| 左半中部 | `avgCost` | 平均持仓成本 |
| 右半 | 迷你 K 线 + `mainCost` 虚线 | 60 日 K 线叠加主力成本线(蓝色虚线) |

```typescript
interface CostDistribution {
  profitRatio: number    // 获利盘比例 0-1
  trappedRatio: number   // 套牢盘比例 0-1
  avgCost: number        // 平均成本
  mainCost: number       // 主力持仓成本
}
```

### 2.6 预测目标价 (TargetPriceCard)

**数据来源**：不调 REST API，从主控台 `DecisionCardData.result`（AI 对话产生的 composite_decision）解析。

**API**：`GET /api/stock/kline?symbol={symbol}&timeframe=1d&limit=60`（仅用于趋势线绘制）

```typescript
interface ParsedResult {
  resistance?: number          // 阻力位/目标价
  entry_price?: number         // 入场价
  estimated_win_rate?: number  // 预估胜率(%)
  support?: number             // 支撑位
  direction?: string           // 'buy' | 'sell' | 'neutral'
  confidence?: number          // 置信度 0-1
}
```

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 目标价 | `resistance` | 蓝色大字 |
| 区间 | `entry_price` ~ `resistance` | 入场至目标 |
| 方向标签 | `direction` | 看多(红) / 看空(绿) / 中性(灰) |
| 胜率 | `estimated_win_rate` | 百分比 |
| 趋势图 | 收盘价折线 + 4 条虚线 | 最高(红) / 最低(绿) / 目标(蓝) / 入场(灰) |

**方向标签映射**：`buy` → 看多(红) / `sell` → 看空(绿) / 其他 → 中性(灰)

## 3. 基本面分析看板

### 3.1 看板总览

| 卡片 | 组件文件 | API 端点 | 数据来源 |
|------|----------|----------|----------|
| 财务综合 | `FinancialSummaryCard.tsx` | `GET /api/financial/report` | Python 服务 (stock_financial 表, AkShare 回退) |
| 现金流结构 | `CashFlowCard.tsx` | `GET /api/financial/report` | 同上 |
| 估值水平 | `ValuationCard.tsx` | `GET /api/valuation` | Python 服务 (stock_valuation_daily 表, AkShare 回退) |
| 成长能力 | `GrowthCard.tsx` | `GET /api/financial/report` | 同财务综合 |
| 偿债 & 运营 | `SolvencyCard.tsx` | `GET /api/financial/report` | 同财务综合 |

> **注意**：基本面看板当前为 mock 占位阶段，真实 API 失败时回退 mock 数据并显示 "DEMO" 徽标。

### 3.2 财务综合 (FinancialSummaryCard)

**API**：`GET /api/financial/report?symbol={symbol}`（返回最近 4 期财报）

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 顶部指标卡 | `roe` / `gross_margin` / `net_margin` | ROE(红) / 毛利率(绿) / 净利率(红) |
| 中部双柱状图 | `revenue` / `net_profit` | 营收/净利润双柱(红涨绿跌, 单位亿元) |
| 底部指标表 | 4 期 × 6 行 | ROE / 营收(亿) / 净利润(亿) / 毛利率 / 净利率 / EPS(元) |

### 3.3 现金流结构 (CashFlowCard)

**API**：`GET /api/financial/report?symbol={symbol}`（与财务综合卡共用）

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 顶部指标卡 | `cash_ratio` / 经营现金/净利比 | 现金比率(红) / 经营净利比(蓝) |
| 中部堆叠柱状图 | `cash_flow_op` | 经营(红) / 投资(蓝) / 筹资(灰), 单位亿元 |

> **注意**：后端 abstract 仅有 `cash_flow_op`（经营现金流），投资/筹资现金流暂无字段，用 0 填充。

### 3.4 估值水平 (ValuationCard)

**API**：`GET /api/valuation?symbol={symbol}`

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 2×2 大字网格 | `pe_ttm` / `pe_static` / `pb` / `ps_ttm` | PE(TTM) / PE(静态) / PB / PS |
| 分位色阶条 | PE 分位 / PB 分位 | 目前 mock: 75% / 60%, 偏高用 warning 色 |
| 底部市值 | `market_cap` / `float_market_cap` | 总市值 / 流通市值(转"万亿") |

```typescript
interface ValuationData {
  symbol: string
  trade_date: string
  close_price: number | null
  pe_ttm: number | null            // PE-TTM
  pe_static: number | null         // 静态 PE
  pb: number | null                // 市净率
  ps_ttm: number | null            // PS-TTM
  market_cap: number | null        // 总市值(元)
  float_market_cap: number | null  // 流通市值(元)
  turnover_rate: number | null     // 换手率(%)
  volume_ratio: number | null      // 量比
  source: string                   // 数据源
}
```

### 3.5 成长能力 (GrowthCard)

**API**：`GET /api/financial/report?symbol={symbol}`

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 顶部 CAGR 卡 | `revenue` 首末对比 | 营收 2 年 CAGR(红) |
| 顶部 CAGR 卡 | `net_profit` 首末对比 | 利润 2 年 CAGR(绿) |
| 双折线图 | `revenue_growth` / `profit_growth` | 营收 YoY(红) / 利润 YoY(绿) |

**CAGR 计算**：`calcCAGR(firstVal, lastVal, firstDate, lastDate)` — 首末期对比，按日期差推算年数。

### 3.6 偿债 & 运营 (SolvencyCard)

**API**：`GET /api/financial/report?symbol={symbol}`

| 显示区域 | 字段 | 颜色规则 |
|----------|------|----------|
| 资产负债率 | `debt_ratio` | <50% 好(绿) / <70% 中(黄) / ≥70% 差(红) |
| 流动比率 | `current_ratio` | ≥2 好 / ≥1 中 / <1 差 |
| 速动比率 | `quick_ratio` | ≥1 好 / ≥0.5 中 / <0.5 差 |
| 期间费用率趋势 | `cost_ratio` (4 期) | CSS div 柱状图 |

### 3.7 财务数据完整字段定义

所有基本面卡片共享 `FinancialAbstract` 数据结构：

```typescript
interface FinancialAbstract {
  symbol: string              // 股票代码
  report_date: string         // 报告期 yyyy-MM-dd
  report_type: string         // Q1/Q2/Q3/Q4
  roe: number                 // 净资产收益率(%)
  roa: number                 // 总资产收益率(%)
  gross_margin: number        // 毛利率(%)
  net_margin: number          // 净利率(%)
  operating_margin: number    // 营业利润率(%)
  revenue: number             // 营业总收入(元)
  net_profit: number          // 归母净利润(元)
  cash_flow_op: number        // 经营现金流量净额(元)
  revenue_growth: number      // 营收增长率(%)
  profit_growth: number       // 利润增长率(%)
  debt_ratio: number          // 资产负债率(%)
  current_ratio: number       // 流动比率
  quick_ratio: number         // 速动比率
  eps: number                 // 每股收益(元)
  bvps: number                // 每股净资产(元)
  cfps: number                // 每股现金流(元)
  cash_ratio: number          // 经营现金/净利润
  cost_ratio: number          // 期间费用率(%)
  total_equity: number        // 净资产(元)
}
```

**数据新鲜度**：DB 缺失或超过 130 天时从 AkShare `stock_financial_abstract` 实时拉取并入库。

## 4. 市场概览看板

### 4.1 看板总览

**聚合 API**：`GET /api/demo/market-overview`（一次请求返回五卡全部数据）

| 卡片 | 组件文件 | 数据字段 | 数据来源 |
|------|----------|----------|----------|
| 大盘指数 | `IndexCard.tsx` | `indices` + `breadth` | AkShare `stock_zh_index_spot_em` |
| 市场宽度 | `BreadthCard.tsx` | `breadth` | AkShare 全市场涨跌统计 |
| 热点板块 | `SectorHeatCard.tsx` | `sectors` | AkShare `stock_sector_fund_flow_rank` |
| 北向资金 | `NorthFlowCard.tsx` | `northFlow` | AkShare 北向资金接口 |
| 大盘成交 | `VolumeCard.tsx` | `volume` | AkShare 大盘成交统计 |

> **缓存策略**：10 分钟内存缓存(成功) + 60 秒短缓存(失败)；5 源并行拉取 + 12 秒超时兜底。

### 4.2 总数据结构

```typescript
interface MarketOverviewData {
  indices: IndexItem[]       // 四大指数
  breadth: BreadthData       // 市场涨跌宽度
  sectors: SectorItem[]      // 热点板块 TOP8
  northFlow: NorthFlowData   // 北向资金
  volume: VolumeData         // 大盘成交
}
```

### 4.3 大盘指数 (IndexCard)

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 指数行情表 | `name` / `price` / `changePct` / `change` / `amount` | 指数名/最新价/涨跌幅/涨跌额/成交额 |
| 底部摘要 | 全市场成交 / `up`:`down` 涨跌比 / 指数均涨幅 / 市场情绪 | 4 格摘要 |

**四大指数**：上证指数(000001) / 深证成指(399001) / 创业板指(399006) / 科创50(000688)

**市场情绪判定**：均涨幅 >0.5% → 偏多 / <-0.5% → 偏空 / 否则 → 震荡

```typescript
interface IndexItem {
  code: string          // 指数代码
  name: string          // 指数名称
  price: number         // 最新价
  change: number        // 涨跌额
  changePct: number     // 涨跌幅(%)
  volume: number        // 成交量
  amount: number        // 成交额
}
```

### 4.4 市场宽度 (BreadthCard)

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 涨跌比例条 | `up` / `flat` / `down` | 涨(红) / 平(灰) / 跌(绿) 三段水平条 |
| 涨跌停 | `limitUp` / `limitDown` | 涨停家数(红) / 跌停家数(绿) |
| 情绪一句话 | 基于 `up`/`down` 比例 | "偏多,赚钱效应较好" / "平衡,方向不明朗" / "偏空,谨慎观望" |

```typescript
interface BreadthData {
  total: number         // 全市场股票数
  up: number            // 上涨家数
  down: number          // 下跌家数
  flat: number          // 平盘家数
  limitUp: number       // 涨停家数
  limitDown: number     // 跌停家数
}
```

### 4.5 热点板块 (SectorHeatCard)

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 垂直列表 | `name` / `changePct` / `netFlow` | 板块名 + 强度条(红涨绿跌) + 涨跌幅 |
| 强度条宽度 | `|changePct| / maxAbs` | 按最大绝对涨跌幅归一化 |

```typescript
interface SectorItem {
  name: string          // 板块名称
  changePct: number     // 涨跌幅(%)
  netFlow: number       // 主力净流入(元)
}
```

**数据来源**：AkShare `stock_sector_fund_flow_rank`（概念板块资金流排行 TOP8）

### 4.6 北向资金 (NorthFlowCard)

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 当日净额 | `todayNet` | 大数(红入绿出) |
| 买入/卖出 | `todayBuy` / `todaySell` | 明细 |
| 近 5 日柱状图 | `dailyFlow[].netFlow` | 双向(中线之上红入 / 之下绿出) |

```typescript
interface NorthFlowData {
  todayNet: number              // 当日净买入额
  todayBuy: number              // 当日买入额
  todaySell: number             // 当日卖出额
  dailyFlow: NorthDailyFlow[]   // 近 5 日流向
}

interface NorthDailyFlow {
  date: string
  netFlow: number
}
```

### 4.7 大盘成交 (VolumeCard)

| 显示区域 | 字段 | 说明 |
|----------|------|------|
| 当日成交额 | `todayAmount` | 大数 + 涨跌幅(红涨绿跌) |
| 当日成交量 | `todayVolume` | 转"亿手/万手" |
| 近 10 日趋势 | `daily[].amount` | 迷你折线图(SVG, 蓝色 `#3b82f6`) |

interface VolumeData {
  todayAmount: number           // 当日成交额(元)
  todayVolume: number           // 当日成交量(手)
  amountChange: number          // 成交额涨跌幅(%)
  daily: VolumeDaily[]          // 近 10 日趋势

interface VolumeDaily {
  date: string
  amount: number                // 成交额
  volume: number                // 成交量
}

## 6. 通用机制

### 6.1 双后端职责分工

| 职责 | Java 后端 (8879) | Python 服务 (8002) |
|------|-------------------|---------------------|
| K 线/行情/指标 | 高频读操作, 直接查 MySQL | 数据采集 + 同源备用 |
| 技术指标计算 | `IndicatorService` (MA/EMA/MACD) | — |
| 财务/估值数据 | — | AkShare 实时拉取 + DB 缓存 |
| 市场概览聚合 | 基础指数/排名 | 5 源并行聚合 + DEMO 特色 |
| AI 卡片解读 | — | `POST /api/analysis/interpret` |

### 6.2 数据新鲜度策略

| 数据类型 | 新鲜度窗口 | 回退策略 |
|----------|-----------|----------|
| K 线/行情 | 实时(WebSocket) / DB 最新 | Java 查 MySQL, Python 同源备用 |
| 财务数据 | 130 天 | DB 超期 → AkShare 实时拉取并入库 |
| 估值数据 | 3 天 | DB 超期 → 东财优先, 新浪兜底 |
| 市场概览 | 10 分钟缓存 | AkShare 5 源并行, 12 秒超时 → Mock 降级 |

### 6.3 前端 Hooks 层

| Hook 文件 | 用途 | 主要函数 |
|-----------|------|----------|
| `useKlineApi.ts` | K 线/行情/详情 | `fetchKlineHistory`, `fetchQuote`, `fetchDetail` |
| `useFundamentalApi.ts` | 财务/估值 | `fetchFinancialAbstract`, `fetchFinancialReport`, `fetchValuation` |
| `useMarketApi.ts` | 市场概览 | `fetchMarketOverview` |
| `useDemoApi.ts` | DEMO 级数据 | `fetchShareholders`, `fetchFundFlow` |

### 6.4 DEMO 数据降级机制

- **基本面看板**：真实 API 失败时回退 mock 数据，卡片右上角显示 "DEMO" 徽标
- **技术面/市场看板**：`/api/demo/*` 端点失败时显示重试按钮
- **目标价卡**：无 `DecisionCardData` 时显示"暂无 AI 预测"占位
