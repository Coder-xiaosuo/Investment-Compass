# Investment-Compass 项目汇报总纲

> 投资罗盘 / 团团投顾 —— A 股投研 AI 助手
> Logo：小马团团（logo.jpg）

---

## 一、项目定位

Investment-Compass（投资罗盘 / 团团投顾）是一款面向 A 股市场的智能投研助手，核心提供**「估值评估 + 技术分析」两阶段决策服务**。通过 AI Agent 编排 + 规则引擎 + RAG 经验库的组合，将专业投研流程沉淀为可复用、可复盘、可进化的决策链路，最终输出有依据、有卡片、可回溯的买卖建议。

- **目标用户**：个人投资者、轻量级投研用户
- **核心价值**：把机构级「先看价值、再看技术、再做决策」的投研流程 AI 化
- **形态**：本地化三层服务（Java 后端 + Python AI 服务 + React 前端），支持私有部署

## 二、三层服务架构

### 1. Java 后端（端口 8879）

- **技术栈**：Spring Boot 3.5.14 + Java 21 + MyBatis-Flex + MySQL + Redis
- **核心控制器**：
  - `StockController`：股票搜索 / 实时行情 / K 线 / 技术指标
  - `WatchlistController`：自选股 CRUD
  - `MarketBoardController`：指数行情 / 排名看板
  - `MonitorController`：数据质量监控
- **实时推送**：
  - WebSocket 端点 `/ws/quote` 推送实时行情
  - Redis 订阅 `quotes` 频道 → WS 转发至前端

### 2. Python 服务（端口 8002）

- **技术栈**：FastAPI + LangGraph + Deep Agents + AkShare + ChromaDB
- **API 规模**：41 个端点
  - 健康检查 / 偏好 / 风格画像 / 行情同步 / K 线 / 对话 SSE / AI 解读 / 资讯 / DEMO 看板 / 财务估值
- **Agent 架构**：1 个主 Agent + 6 个子 Agent
  - `value_assessment`：价值评估
  - `technical_analysis`：技术分析
  - `pa_agent`：PA 策略分析
  - `advisory`：投顾建议
  - `ai_reader`：资讯 / 研报 AI 解读
  - `watchlist_manage`：自选股管理
- **Service 层**：27 个 Service
  - `chat_service` / `sync_service` / `experience_library` / `style_profiler` / `backtest_service` 等
- **PA 策略 Skill**：33 个（`pa_analyzer/skills/` 目录）
- **规则引擎**：
  - `gates.py`：门控逻辑
  - `scorer.py`：五维度评分
- **经验库 RAG**：
  - Chroma 向量库
  - bge-small-zh-v1.5 嵌入模型
  - 三层检索（结构化过滤 + 语义排序 + 时间衰减 + 复盘验证权重）

### 3. 前端（Vite 默认 5173）

- **技术栈**：React 19 + TypeScript + Vite 8 + TailwindCSS v4 + Lightweight Charts v5
- **布局**：三栏
  - 左栏 `Sidebar`（导航 / 自选股）
  - 中间 `MainArea`（主工作区）
  - 右栏 `RightPanel`（上下文 / 辅助对话）
- **两种模式**：
  - **分析模式**：AI 对话 + HITL 人工干预 + 决策卡片
  - **操盘模式**：技术面 / 基本面 / 市场概览看板
- **特性**：
  - 自研组件，零第三方 UI 库依赖
  - SSE 流式对话 + 节流渲染优化
  - 投资风格画像（六维雷达图 SVG 原生绘制）

## 三、基础设施

### MySQL（3306）

- 数据库：`investment_compass`
- 规模：20+ 张表
  - 用户 / Agent 注册 / 模拟交易 / 决策卡片 / 审计链 / 风控 / 因子 / 行情 / 对话 / 基本面 / 资讯 / 风格画像
- 迁移脚本：13 个（V001–V013）

### Redis（6379）

- `quotes` 频道 Pub/Sub：实时行情广播
- `quote:{symbol}` Hash：行情快照

### ChromaDB

- 集合：`experience_library_zh`（经验库向量检索）
- 嵌入模型：`bge-small-zh-v1.5`

### AkShare（外部数据源）

- 主源：东方财富
- 备源：新浪
- **双源断路器**：自动切换，保障数据可用性

## 四、技术亮点

### 1. 两阶段决策编排

```
估值评估（规则引擎五维度评分 + LLM 定性重评）
        ↓
HITL 中断征求用户决策（approve / reject / respond）
        ↓
技术分析（LangGraph 7 节点两阶段）
  ├─ Stage1：市场诊断
  └─ Stage2：交易决策
        ↓
汇总输出（决策卡片 / 报告 / 飞书通知）
```

### 2. HITL 人工干预

- 基于 MySQL `AIOMySQLSaver` checkpointer 持久化中断状态
- `confirm_proceed_analysis` 中断点支持三种用户响应：
  - `approve`：继续技术分析
  - `reject`：终止流程
  - `respond`：补充信息后继续

### 3. 经验闭环 RAG

- **读侧**：`inject_experience` 注入历史案例（含失败反例，用于规避重复错误）
- **写侧**：`experience_loop_service` 复盘回填 `review_outcome`，提升进 Chroma
- **三层检索**：结构化过滤 + 语义排序 + 时间衰减 + 复盘验证权重

### 4. 双源断路器

- 东财主源 ⇄ 新浪备源
- 状态机：`closed` / `open` / `half_open`
- 整批全局切换，避免单点失败影响整批数据

### 5. 33 个 PA 策略 Skill

- 按通道类型 / 方向 / A 股信号动态路由加载
- 覆盖 A 股专属策略：
  - 涨停板分析
  - 缺口策略
  - 支撑阻力
  - 板块联动
  - 上涨 / 下跌 / 极速 / 震荡 / 楔形 / 三角形 / 双重顶底等通道与形态策略

### 6. 投资风格画像自进化

```
冷启动问卷（30 题）
   ↓
六维雷达图（SVG 渲染）
   ↓
HITL 反馈自进化
  ├─ feedback_signals 表记录反馈
  └─ LLM 推断调整画像维度
```

### 7. 防未来函数回测

- `set_backtest_asof` 注入历史时点
- 财务 / 估值接口均以 `as_of` 时间回溯，确保回测结果真实可信

### 8. 实时行情推送链路

```
Python AkShare  →  Redis Pub/Sub  →  Java WebSocket  →  前端
```

### 9. trace_id 幂等

- 决策幂等键贯穿全链路：
  - 决策卡片
  - 报告文件
  - 飞书推送
- 保障同一决策不会被重复创建或推送

## 六、Demo 演示建议路径
