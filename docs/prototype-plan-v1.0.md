## 三、价值评估 Agent 设计

### 3.1 三层价值评估流程

```
用户 → "分析茅台"
  │
  ├── 第一层：规则闸门（亚毫秒，免费）
  │   ├─ ST/*ST/上市不足1年/数据缺失
  │   │   → 直接回复"该标的建议回避"，结束
  │   └─ 通过
  │
  ├── 第二层：规则评分（1-5 毫秒，免费）
  │   ├─ 结构化打分（见 3.2 评分公式）
  │   ├─ < 40 分 → 回复"基本面偏差，不推荐"，结束（省 LLM 和 PA token）
  │   └─ ≥ 40 分
  │
  ├── 第三层：LLM 重打分（几秒，~3-8k token）
  │   ├─ 数据注入：财务摘要 + 规则评分各维度结果
  │   ├─ LLM 综合评判：带推理的人话输出
  │   ├─ 未来可扩展：Tool/MCP 接入 → 研读最新财报/政策/新闻
  │   └─ 评分依然偏低 → 回复"谨慎"，结束
  │
  └── PA Agent 技术分析（40-60s，~180k token）
      → 综合决策 → 输出
```

**串行过滤链的目的**：每层都可以拦截，越往后成本越高。

| 层级 | 拦截后节省的 Token | 拦截比例（预估） |
|------|-------------------|-----------------|
| 闸门 | PA 180k + LLM 8k | 约 10%（ST/新股/退市等）|
| 规则评分 < 40 | PA 180k + LLM 8k | 约 50%（基本面差股）|
| LLM 重评分 | PA 180k | 约 10%（LLM 审查后认为不可靠）|
| **最终需进 PA** | — | **约 30%** |

### 3.2 评分公式（规则层）

```
综合价值评分 = 盈利能力(30%) + 成长性(25%) + 估值(20%) + 财务健康(15%) + 收益质量(10%)

各维度计分规则（0-100 分）：
  盈利能力 = ROE 分 + 毛利率分 + 净利率分 的加权
    ├─ ROE: <5% → 0分, 5-10% → 40分, 10-15% → 60分, 15-20% → 80分, >20% → 100分
    ├─ 毛利率: <20% → 0分, 20-40% → 40分, 40-60% → 70分, 60-80% → 85分, >80% → 100分
    └─ 净利率: <5% → 0分, 5-10% → 40分, 10-20% → 70分, >20% → 90分

  成长性 = 营收增速分 + 利润增速分 的加权
    ├─ 营收增速: <0% → 0分, 0-10% → 40分, 10-20% → 70分, 20-30% → 85分, >30% → 100分
    └─ 利润增速: <0% → 0分, 0-10% → 40分, 10-20% → 70分, 20-30% → 85分, >30% → 100分

  估值 = PE 分 + PB 分 的加权（行业相对）
    ├─ PE: 行业百分位 <20% → 80分, 20-40% → 60分, 40-60% → 50分, 60-80% → 30分, >80% → 10分
    └─ PB: 同上

  财务健康:
    ├─ 资产负债率: <30% → 90分, 30-50% → 70分, 50-70% → 40分, >70% → 10分
    └─ 流动比率: >2.0 → 90分, 1.5-2.0 → 70分, 1.0-1.5 → 40分, <1.0 → 10分

  收益质量:
    └─ 经营现金流/净利润: >1.0 → 90分, 0.5-1.0 → 60分, <0.5 → 20分

  行业修正（加权前 × 行业调整系数）:
    ├─ 消费/医药: 盈利权重+10%, 成长权重-5%
    ├─ 科技: 成长权重+10%, 盈利权重-5%
    ├─ 金融: 盈利权重+5%, 成长-10%, 财务健康权重+5%
    └─ 周期: 估值权重+10%, 成长权重-5%

总分 100 分制:
  ≥ 80: 优质（强烈关注）
  60-79: 良好（可关注）
  40-59: 一般（观望）
  < 40: 差（回避）
```

### 3.3 闸门规则（先于评分执行）

| 条件 | 结果 |
|------|------|
| ST / \*ST | ❌ 直接回避 |
| 上市 < 1 年 | ⚠️ 数据不足，评分不可靠 |
| 最新 ROE < 0 | ❌ 直接回避 |
| 资产负债率 > 90% | ❌ 直接回避 |
| 营收/利润连续 2 年下滑 | ⚠️ 标记负面趋势，LLM 重点审查 |

### 3.4 LLM 重打分设计

**输入数据**（注入 LLM 上下文）：

```
股票：贵州茅台（600519）
行业：食品饮料（白酒）

规则评分结果：
  综合：85/100（优质）
  盈利能力：95（ROE 32.1%，毛利率 91.3%，净利率 49.8%）
  成长性：75（营收同比+15.2%，利润同比+18.7%）
  估值：70（PE 32.6倍，行业百分位 55%）
  财务健康：90（负债率 19.8%，流动比率 3.2）
  收益质量：85（经营现金流/净利润 1.15）

最新一期报告摘要：
  报告期：2026Q1
  营业总收入：547亿（同比+15.2%）
  归母净利润：272亿（同比+18.7%）
  毛利率：91.3%
  净利率：49.8%
  经营现金流：312亿
```

## 四、综合决策融合

### 4.1 融合逻辑

```
价值评分 ≥ 60（良好以上）
  ├─ PA: 买入 → ✅ 强烈买入
  ├─ PA: 观望 → ⏳ 等买点
  └─ PA: 卖出 → ⚠️ 减仓/警惕

价值评分 40-59（一般）
  ├─ PA: 买入 → 🟡 轻仓试水
  ├─ PA: 观望 → ⏳ 不关注
  └─ PA: 卖出 → 🔴 清仓

价值评分 < 40（差）
  ├─ PA: 买入 → ❌ 不建议追涨
  ├─ PA: 观望 → ❌ 不关注
  └─ PA: 卖出 → 🔴 清仓
```

### 4.2 输出格式

```
📊 贵州茅台（600519）综合评估
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎯 综合决策：⏳ 等买点

📈 价值评估：85/100（优质）
   ─ 盈利能力：95（ROE 30%+，毛利率 91%）
   ─ 成长性：75（营收+15%，利润+18%）
   ─ 估值：70（PE 32倍，行业中等）
   ─ 财务健康：90（负债率 20%）

📉 技术分析：观望
   ─ 趋势：上升趋势（置信度 78%）
   ─ 形态：日线级别收窄三角
   ─ 入场：等待突破1630确认后入场
   ─ 止损：跌破1580离场

💡 建议：
   优质标的，但当前技术面未给出入场信号。
   建议等待日线突破1630元后分批建仓，
   参考区间 1630-1680 元。
```
