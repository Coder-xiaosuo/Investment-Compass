## 2. 实现逻辑

### 2.1 架构设计

意图识别Agent采用**模型优先+规则兜底**的混合策略：

```
用户输入
    │
    ▼
┌─────────────────────┐
│ 模型分类器（主流程）   │  ← DeepSeek V3 Lite
│ • 意图分类            │
│ • 实体提取            │
│ • 上下文感知          │
└──────────┬──────────┘
           │
           ▼
    模型可用？
    ├── 是 → 返回模型结果
    └── 否 → 降级到规则引擎
           │
           ▼
    ┌─────────────────────┐
    │ 规则引擎（降级方案）   │  ← 关键词+正则匹配
    │ • 意图分类            │
    │ • 动作分类            │
    │ • 实体提取            │
    └─────────────────────┘
```

### 2.2 核心组件

| 组件 | 职责 | 技术实现 |
|------|------|---------|
| **ModelClassifier** | 调用LLM进行意图分类 | DeepSeek API + JSON输出约束 |
| **RuleEngine** | 规则匹配兜底 | 关键词命中 + 正则匹配 + 置信度计算 |
| **ChangeDetector** | 检测意图/实体变更 | 对比当前与历史状态 |
| **ContextManager** | 上下文继承 | 未变更实体自动继承 |

### 2.3 提示词设计

系统提示词采用结构化设计，包含：
- **角色定义**：投资罗盘桌面客户端的意图识别助手
- **意图分类**：3类意图（investment_analysis/general_chat/watchlist_manage）配详细边界说明
- **实体规范**：5种实体类型（symbol/stock_name/timeframe/date_range/strategy）配枚举约束
- **置信度校准**：4档参考标准（0.9-1.0/0.7-0.9/0.5-0.7/0.0-0.5）
- **输出格式**：强制JSON，含intent/entities/confidence/intent_changed/change_reason

### 2.4 关键特性

1. **股票名称识别**：LLM能识别"贵州茅台"、"五粮液"等中文名称，自动映射到代码
2. **否定语境理解**："不对，我问的是五粮液" → 正确识别为更换股票，非闲聊
3. **上下文继承**：多轮对话中自动继承未变更实体（如symbol）
4. **意图变更检测**：显式检测意图切换和实体变更

## 5. 错误分析

### 5.1 唯一错误用例

| 项目 | 内容 |
|------|------|
| **ID** | 23 |
| **输入** | "你好，能帮我分析一下吗" |
| **预期意图** | investment_analysis |
| **实际意图** | general_chat |
| **置信度** | 0.40 |
| **类别** | 问候+投资分析（混合） |

### 5.2 错误原因分析

该用例为**混合场景**——用户以问候开场，随后提出投资分析请求。模型被"你好"引导，且后半句"能帮我分析一下吗"缺少具体股票对象，导致模型无法确定这是投资分析请求。

**影响评估**：低。在实际多轮对话中，用户通常会继续补充具体股票，模型在第二轮能正确识别。

### 5.3 改进建议

1. **混合场景处理**：可考虑在首轮识别为general_chat且置信度<0.5时，引导用户补充具体需求
2. **缺失对象处理**："分析一下"无股票对象时，可结合上下文推断或主动询问

## 8. 测试结论

### 8.1 总体评价

意图识别模块在50个单轮测试用例和5组多轮测试中表现**优秀**，综合准确率达到**98.2%**。模型能够：

1. **准确分类三大意图领域**，投资分析类100%准确
2. **精准提取股票实体**，支持中文名称、代码、简称
3. **正确处理多轮上下文**，实体继承和意图切换检测准确
4. **合理处理模糊输入**，低置信度标记便于后续澄清

### 8.2 已知限制

1. **混合场景（问候+请求）**：可能被误判为闲聊（1/50）
2. **缺少对象的请求**：如"帮我看看"无明确股票时可能无法分析
3. **模型依赖**：需要配置API key，无网络时降级到规则引擎

### 8.3 后续优化方向

1. **V1.1**：优化混合场景处理，增加首轮引导逻辑
2. **V1.2**：补充更多边缘用例测试（英文输入、表情符号等）
3. **V2.0**：引入规则引擎辅助，模型+规则融合提升准确率至99%+
